# 지역 유가 지도 사용법

1. Windows에서 `start.cmd`를 더블클릭한다. 기본 브라우저가 열리지 않으면 실행 창에 표시된 `Local URL`을 복사해 Edge 또는 Chrome에서 연다.
2. **지역 데이터 추출**에서 주유소 기본정보 CSV와 판매가격 CSV를 각각 선택한다. 시·도와 시·군·구를 고른 뒤 두 저장 버튼을 누른다. 시·군·구의 **전체**는 선택한 시·도 전체를 뜻한다.
3. **메인으로 돌아가기**를 누르고 **지도에서 주유소·유가 조회**를 연다. 앞에서 저장한 파일 두 개를 선택하고 지도에서 주유소 마커를 누른다. 가격과 날짜를 오른쪽에 표시한다.
4. 사용을 마치면 실행 창을 닫거나 `Ctrl+C`로 종료한다.

샘플 CSV 두 개와 원본 행정동 경계는 `전국주유소표준데이터` 폴더에 있다. 앱을 옮길 때는 이 폴더와 지도용 `boundaries` 폴더, 실행 파일, HTML, CSS, JavaScript 파일을 함께 옮긴다. 실행에 Windows PowerShell과 최신 Edge 또는 Chrome을 사용하며 패키지 설치나 인터넷 연결은 필요 없다. CSV는 브라우저에서 읽으며 결과는 브라우저의 다운로드 설정에 따라 저장된다.

지도에서 드래그해 이동하고, 마우스 휠 또는 +와 − 버튼으로 확대·축소한다. 지도에 키보드 초점이 있을 때 방향키와 +, −, Home 키를 사용할 수 있다. 회색 마커는 위치를 표시할 수 있으나 상호와 주소로 판매가격을 하나로 연결하지 못한 주유소다.

샘플로 시험하려면 경기도 고양시를 선택한 뒤 지도에서 (주)원일석유 능곡주유소를 찾아 2026년 11월 21일 휘발유 1,934원/L와 경유 1,923원/L를 확인할 수 있다.

지도 메뉴에서는 CSV로 조회 지역이 정해지면 해당 시·도의 경계를 자동으로 불러온다. 경계 로딩 오류가 계속되면 **로컬 행정동 경계 파일 선택**에서 `전국주유소표준데이터/HangJeongDong_ver20261001.geojson`을 연다. 지역 데이터 추출에는 경계 파일이 필요 없다.

메인 화면 배경에는 앱 폴더의 `coastal-sunset.webp`를 사용한다.

원본 GeoJSON을 수정했다면 Node.js에서 `node build-boundaries.cjs`를 실행해 지도용 파일을 갱신한다.
